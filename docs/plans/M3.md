# M3 — Effects (plan)

No sim changes: every effect is derived in the app layer by diffing the previous and next `GameState`.
Already done in M2: copy picked by seed (`pickCopy`), wave fanfare notice, hang countdown text.

| # | Task | Files | Test / check |
|---|---|---|---|
| 1 | `fxEvents(prev, next)`: pure diff → `spawn{kind}`, `close{x,y,w,h}`, `combo{n}`, `wave{kind}`, `forceQuit`, `taskManager`, `crash` | `src/app/events.ts`, `events.test.ts` | Vitest: one case per event, none on identical states |
| 2 | `audio.ts`: WebAudio synth — spawn blip per kind, close click, combo arpeggio, RAM alarm >75% (pulse follows RAM), crash falling chord + modem noise. Unlocks on first pointer/key. Mute from settings | `src/app/audio.ts`, `main.ts` | Pure helpers (`blipFreq`, `alarmPeriodMs`) unit-tested; no console errors |
| 3 | Pop-in (4-frame scale) and close puff | `render.ts`, `styles.css` | Screenshot mid-spawn |
| 4 | Combo popups "×4!" at the close point | `fx.ts`, `styles.css` | Screenshot after 3 quick closes |
| 5 | Screen shake >80% RAM, red vignette during a hang | `fx.ts`, `styles.css` | Screenshot at high RAM |
| 6 | Cursor trail (canvas or DOM dots, app-only) | `fx.ts` | Visual check |
| 7 | Crash screen: CRT scanlines, results count up | `main.ts`, `styles.css`, `layout.ts` (`countUp` helper) | `countUp` unit test; screenshot |
| 8 | Reduced motion: no shake, trail or pop-in scale (`prefers-reduced-motion`) | `styles.css`, `fx.ts` | Emulated reduced-motion screenshot |

Constraints: palette from SPEC §9, nothing flashes more than 3×/s, effects never write to sim state.
