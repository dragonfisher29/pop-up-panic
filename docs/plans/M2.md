# M2 — Chaos: task list

Start commit: `bdd4a1d`. Each task: failing test first (sim), then code, then commit `M2: <task>`.

1. **World + director** — `src/sim/world.ts` (spawnWindow, play area, closeWindows with combo), director in `src/sim/director.ts`: unlock waves, weighted pick (newest ×2 for 10 s), bursts every 25 s (3–5 within 400 ms), antivirus 1-in-25 after 20 s. Types + constants for all 8 kinds. Test: `director.test.ts`.
2. **Simple kinds** — `kinds/ad.ts`, `fakeX.ts` (X spawns an ad, link closes), `prize.ts` (3 s timer → 4 ads; CLAIM triggers it), `virusScan.ts` (X → 2 more, Cancel closes). Tests: one file per kind.
3. **runner** — flees at 6 px/tick within 90 px, after a one-time 300 ms tell (`tellUntilTick`). Test: `runner.test.ts`.
4. **confirm** — chain of 2–3 stages; last Yes closes the whole chain; No does nothing. Test: `confirm.test.ts`.
5. **toolbar** — installer close/Install attaches a 40 px strip (max 4); area shrinks for spawns, drags and existing windows; tray click uninstalls. Test: `toolbar.test.ts`.
6. **antivirus** — eats the oldest hostile every 4 s (tell first); closing it = +15% RAM spike for 1 s. Test: `antivirus.test.ts`.
7. **Panic tools** — Force Quit (3 charges, +1 / 45 s, skips tricks) and Task Manager (once, closes all hostile, 1.5 s flash). Test: `tools.test.ts`.
8. **Determinism + bot** — 3-minute scripted run replays byte-identically; `scripts/sim-bot.ts` (`npm run sim:bot`), 200 seeds, tune to median 90–140 s.
9. **App** — copy for all kinds, per-kind window bodies, tells, strips, tool keycaps in HUD (Space / right-click / Shift), wave fanfare, Task Manager flash, antivirus penalty toast. Check in Playwright.

## Decisions on SPEC gaps (flag to owner)
- Wave fanfare shows when a type unlocks; bursts run on their own 25 s clock (the two schedules don't line up in SPEC).
- Combo counts one per close *action*: a chain close or Task Manager adds `combo × windows` points but raises combo once.
- Antivirus and prize self-closes don't score. Force Quit on the antivirus skips the spike.
